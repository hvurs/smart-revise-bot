Smart Revise Bot

A browser console script that fills in Smart Revise answers for OCR GCSE Computer Science (J277) from a CSV of stored answers.

answers.csv script.js GitHub

Setup

  • 1. Open the console

    Press F12 in your browser.

  • 2. Run the script

    Paste the contents of script.js into the console and press Enter.

  • 3. Get the answers

    Download answers.csv using the button above.

  • 4. Import them

    Click Import CSV and choose answers.csv.

Answer coverage

All units are covered. From 1.1 all the way to 2.5 (basically, it covers both components). If they add new questions the bot may get stuck on it, however until then, it is fully functional. In the future, I will add it so it purposefully gets questions it doesn't know wrong, that way next time the question appears, the script already knows the answer. I'll also add so the answer list is constantly updating, using the most recent version.

Use it wisely

Automating the task doesn't count as revision. Use it to check your work or save time on questions you already know, and still go through the material yourself.
