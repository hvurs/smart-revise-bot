Smart Revise Bot

A browser console script that fills in Smart Revise answers for OCR GCSE Computer Science (J277). It loads its answers straight from this project's GitHub and learns any it doesn't know.

answers.csv script.js GitHub

Setup

  • 1. Copy the script

    Hit Copy script at the top of this page.

  • 2. Open the console

    On the Smart Revise tab, press F12 and open the Console tab.

  • 3. Paste and press Enter

    A panel appears at the bottom right of the page and the answers download automatically.

If your browser blocks pasting into the console, type allow pasting, press Enter, then paste again. You'll need to run the script again after refreshing the page.

How it works

Once a second or so the script checks which question is on screen and looks it up in a list of stored answers. What happens next depends on whether it finds one.

  • It knows the question

    It waits a few seconds so it looks natural, clicks the matching option, then moves on to the next question.

  • Several options match

    Sometimes more than one stored answer shows up as an option. It picks one at random. If it's wrong, the site reveals the right one and the bot saves it.

  • It doesn't know the question

    It clicks "I don't know", reads the correct answer the site then shows in green, and saves it for next time.

  • Staying up to date

    Every time you run it, the script pulls the latest answers.csv from GitHub, so you always have the newest list. Anything it learns is kept in your browser, and you can send new answers back with the Report new answers button, which opens a pre-filled GitHub issue for you to submit.

A small tag above each question shows what the bot is doing, so you can tell it hasn't frozen during the delay.

  • Bot: Known It has the answer and will click it shortly.
  • Bot: Ambiguous More than one option matches, so it will pick one.
  • Bot: Learning New question. It will click "I don't know" to learn it.
  • Bot: Stuck It can't act on this one (for example there's no "I don't know" button). Answer it yourself and it will still save the answer.
  • Bot: Paused You stopped it from the panel, so nothing happens.

Once a question is done the tag changes to Answered, Guessed, Learned or Manual, depending on how it was handled.

Answer coverage

All units are covered, from 1.1 all the way to 2.5, so both components. If Smart Revise adds new questions, the bot learns them the first time it sees them and the answer list gets updated from there.

Support

Open a GitHub issue For bugs, wrong answers, or questions the bot gets stuck on. diego@hvurs.cc For anything private.

Use it wisely

Automating the task doesn't count as revision. Use it to check your work or save time on questions you already know, and still go through the material yourself. Only paste scripts into your console that you trust, and that includes this one: read it first, it's all in the repo.
