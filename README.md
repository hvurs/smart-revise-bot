# Smart Revise bot 

This is a simple script that you enter into your browser console. It automatically answers your Smart Revise questions for you, for the Computer Science GCSE OCR J277 course. Requires minimal setup as well.

## Setup 
1. Open your console by pressing `F12` on your keyboard
2. Paste `script.js` into your console
3. Download `answers.csv`
4. Click import CSV and import `answers.csv`
5. Done

## Answers
Contains pretty much all answers from Component 1 and Component 2, however smart revise tends to lie to me so there may be a few missing. Luckily, the bot quickly learns answers it doesn't know + allows you to report it in 2 clicks as a github issue - that way, you always get the most recently updated answers & can contribute to other peoples experience!

## Use 
Use it however you like, but purely using this to automate revision, won't actually count as revision. When I did this task, I had to manually go through every question myself at least once in order to complete the answers.csv (that's 433 questions btw)
