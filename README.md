# Smart Revise bot 

This is a simple script that you enter into your browser console. It automatically answers your Smart Revise questions for you, for the Computer Science GCSE OCR J277 course. Requires minimal setup as well.

## Setup 
1. Open your console by pressing `F12` on your keyboard
2. Paste `script.js` into your console
3. Download `answers.csv`
4. Click import CSV and import `answers.csv`
5. Done
